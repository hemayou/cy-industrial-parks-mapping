# 朝阳园产业园区地图

面向朝阳园产业园区专题制图的 Web Map，供同事交互出图，也便于通过 Coding Agent 扩展专题图层。

## 项目范围

- 使用覆盖北京市的 Esri 和 CARTO 深浅色矢量底图，默认按朝阳区完整行政区界确定出图范围，参考样图保留周边少量地理参照。支持切换底图、叠加区界和调整底图标注的字体与字号，并验证道路改色及图层显隐。
- 支持导入 GeoJSON、Shapefile 和 GeoPackage 的点、线、面，按字段生成标注和点分类样式，可调整标注字体、字号和文字样式，以及点符号、大小和颜色。
- 支持 PNG 和 JPG 导出。默认预设为 A1 竖版（594 × 841 毫米）、300 DPI，对应 7016 × 9933 像素。出图时可按自定义印刷尺寸和 DPI 换算像素，也可直接编辑像素宽高。按像素出图时，根据所选 DPI 显示对应的印刷尺寸。导出图片写入所选 DPI 的分辨率元数据。
- 首版提供可直接导出的专题图模板，包含可编辑的图名、根据园区点分类及配色自动生成的图例，以及指北针。

## 底图标注规则

底图地理标注只显示可确认的简体中文名称。要素缺少可确认的中文名时，保留图形，文字标注留空。

## 成图样式定制

- 园区点按类别设置符号形状、大小、颜色和描边。区块面可调填色、透明度和边线。行政区界和线图层可调线色、线宽和线型。
- 底图地名、园区名称和区块名称分别调整字体、字号、文字颜色和描边。
- 图例随当前园区点分类及配色更新，可调整版位、分栏、类别顺序、字体字号、符号大小和背景。图名和指北针可调整版位与尺寸。

## 样图与验收重点

同事提供的样图用于参考朝阳区全域取景、园区点分类、区块叠加和编号名录的版式。正式园区点位和区块从原始矢量文件导入。

优先按 A1 实际成品尺寸验收朝阳区全域图上中文地名的可读性。环路、主干道、街道和乡镇名称及主要水系应清楚可辨。底图地名与园区标注独立调整字体、字号和对比度，次要底图标注可按需关闭。

## 部署与业务数据

GitHub 公开项目源码。Cloudflare 首版工作页向授权同事开放。正式园区点位和区块文件由浏览器在本地解析、渲染和出图。
