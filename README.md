# 朝阳园产业园区地图

面向朝阳园产业园区专题制图的 Web Map，供同事交互出图，也便于通过 Coding Agent 扩展专题图层。

## 项目范围

- 以北京市为地图工作范围，提供 Esri 和 CARTO 深浅色矢量底图、底图切换和行政区界叠加。提供底图标注字体和字号设置，并验证道路改色及图层显隐。
- 支持导入 GeoJSON、Shapefile 和 GeoPackage，按字段生成标注和点分类样式，可调整标注字体、字号和文字样式，以及点符号、大小和颜色。
- 支持按指定尺寸和 DPI 导出 PNG 或 JPG。交付目标包括 GitHub 开源仓库和 Cloudflare 部署。

## 底图标注规则

底图地理标注只显示可确认的简体中文名称。要素缺少可确认的中文名时，保留图形，文字标注留空。
